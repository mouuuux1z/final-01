# Madika Arabic fonts

Arabic UI uses **Madika Arabic ExtraBold** (headings) with Regular and Medium for body text.

| File | Weight | Expo key |
|------|--------|----------|
| `MadikaArabic-Regular.otf` | 400 | `MadikaArabic_400Regular` |
| `MadikaArabic-Medium.otf` | 500 | `MadikaArabic_500Medium` |
| `MadikaArabic-ExtraBold.otf` | 800 | `MadikaArabic_800ExtraBold` |

Web uses the matching `.woff2` files via `@font-face` in `global.css`.

**License:** Current files are Babelfont TRIAL (evaluation only). For production/App Store, purchase a license from [babelfont.com](https://babelfont.com/shop/fonts/madika/) and replace these files.
